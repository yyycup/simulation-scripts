## 1. 实验设计

对照两个变量，其余全部钉死：

| 变量 | 取值 |
|---|---|
| **E1 冷板内流向** | 正向 1→2→3 / 反向 3→2→1 |
| **E2 管网拓扑** | 同程式（reverse-return）/ 异程式（direct-return） |
| 放电电流 | 560 A / 1120 A |
| 压缩机 / 风机 / 泵转速 | 4000 / 1200 / 3600 rpm（恒定） |
| 总管流量 | 两种拓扑各自重新选泵，使参考流量一致 |

**关键隔离手段**：每种拓扑使用各自的 `build_engineering_pump(network)`。
结果上所有 8 个工况的总管流量均落在 **0.89964 kg/s**，完全一致，
因此拓扑是唯一的自变量。

**异程式如何实现**：`DirectReturnHeaderNetwork` 继承
`ParallelHeaderHydraulicNetwork`，只重写 `_quantities()` 中的回程段流量：

```python
supply_flows = np.cumsum(flows[::-1])[::-1]
return_flows = np.cumsum(flows[::-1])[::-1]   # 父类此处为 np.cumsum(flows)
return_path_delta_p = np.cumsum(return_delta_p)  # 父类此处为 [::-1] 后再 cumsum
```

阻力系数从 `build_medium_header_network()` 原样克隆，只改拓扑。

## 2b. 流量 → 温度的传递灵敏度

把每一支的"流量偏差 %"和"电池最高温变化 K"配对做最小二乘：

| 时刻 | 560 A 灵敏度 | 1120 A 灵敏度 | 拟合最大残差 |
|---|---|---|---|
| 300 s | −0.0145 | −0.0141 | 0.001 K |
| 600 s | −0.0269 | −0.0257 | 0.003 K |
| 1200 s | −0.0403 | −0.0390 | 0.007 K |
| 1800 s | **−0.0445** | **−0.0508** | 0.010 K |

单位：**K / 每 1% 支路流量偏差**。

三个结论：

1. **线性关系在每个时刻都成立** —— 最大残差 0.010 K，相对于 0.6 K 的量程只有 1.6 %。
   流量偏差是温度偏移的**唯一一阶解释变量**。
2. **灵敏度不是常数，随热瞬态长大**。300 s 时 −0.0145，1800 s 时 −0.0445，涨了 3 倍。
   这是热容在积分：温差需要时间积累。外推稳态约 −0.05 K/%。
3. **两种电流的系数几乎相同**（600 s 时 −0.0269 vs −0.0257，差 4.5 %），
   又一次证明这个传递特性由管网和冷板结构决定，与发热功率弱相关。

## 4. 机理

### 4.1 同程式的镜像抵消

支路*i* 在供程走 1..*i* 段、在回程走 *i*..N 段，合计恒为 N+1 = 6 段，
与 *i* 无关。在设计流量 0.44625 kg/s 下逐项拆开：

| 支路 | 支路阻力偏差 Pa | 管段阻力偏差 Pa | 合计 |
|---|---|---|---|
| 1 | +199.3 | −199.3 | 0 |
| 2 | −99.7 | +99.7 | 0 |
| 3 | −199.2 | +199.2 | 0 |
| 4 | −99.7 | +99.7 | 0 |
| 5 | +199.3 | −199.3 | 0 |

五项**精确互为相反数**，五条环路总阻力严格恒等（21 798.9541 Pa，四位小数相同）。
残余的 4.908 % 流量偏差来自阻力律 Δp = R·ṁ² 的**非线性**——
镜像抵消只在偏差一阶意义上成立。残余量随流量平方增长：
0.446 kg/s 时 1.0 %，0.900 kg/s 时 4.9 %。

### 4.2 异程式的单调衰减

回程反向后，支路 *i* 走 2*i* 段管：Pack 1 最短（2 段）、Pack 5 最长（10 段）。
流量单调衰减 0.19639 → 0.17159，极差 13.784 %。
注意异程式的"宠儿"Pack 1 拿到 0.19639，比同程式的任何一支（最多 0.18433）都多；
"弃儿"Pack 5 只有 0.17159。**它既过度喂养近端，又饿死远端。**

### 4.3 流向：入口应该对准最热的一端

`pack_reference.py` 的非均匀产热：

```python
column_factor = 1.0 - 0.4 * col / (self.cols - 1)
```

列 0 因子 1.0（最热），列 12 因子 0.6（最凉）。
冷板 ROM 按 `ZONE_COLUMN_COUNTS = [4, 5, 4]` 切成三个串联区，
Zone 0 = 列 0–3，即**最热的四列**。

- 正向：冷却液入口直接扑在最热区，此处传热温差最大 → 效果最好
- 反向：先流过最凉区被预热，抵达最热区时驱动力已衰减 → 整体恶化

所以**正向（Zone 0 在前）是更优解**，代价仅 0.04~0.07 K。

## 5. 结论

1. **同程式确实自平衡**，且优势是数量级的：流量不均衡度 4.9 % vs 13.8 %，
   Pack 间温差 0.12 K vs 0.33 K。
2. **但同程式并非完美**。4.9 % 的残余偏差是二次阻力律的非线性产物，
   流量越大越明显。若要把这一项也压下去，得靠减小
   `MEDIUM_HEADER_TO_BRANCH_RESISTANCE_RATIO`（现为 0.005，向 0.001 靠）
   或加大支路阻力占比。
3. **能耗上两者打平**。泵功耗、电网侧功率、电网侧 COP 的差异都在 0.05 % 以内——
   异程式没有省下任何泵功，纯粹白送 0.2 K 的温差。
4. **流向的影响远小于拓扑**（0.07 K vs 0.21 K），但方向明确：正向优于反向。
5. **绝对温差尚未收敛**。温度极差在 300/600/1200/1800 s 分别为
   0.070 / 0.132 / 0.198 / 0.220 K，仍在涨但增速放缓。
   本报告 1800 s 数值仍是**稳态惩罚的下界**，外推稳态 Pack 间温差约 0.2 K vs 0.55 K。
6. **流量偏差是温度偏移的唯一一阶解释变量**。逐 Pack 配对后呈严格线性
   （最大残差 0.010 K），灵敏度约 **−0.045 ~ −0.051 K 每 1% 支路流量偏差**（1800 s）。
   这意味着只要算出流量分配，温差分布可以直接预测，不必跑完整热仿真。
