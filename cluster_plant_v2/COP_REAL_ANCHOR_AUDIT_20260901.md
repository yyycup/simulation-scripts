## 0. 结论先行：问题不是物理错了，是核算口径漏了三项

昨天我在 `PROJECT_ANALYSIS_20260901.md` 里判定"模型 COP 高估约 1.5 倍"。**这个说法不准确，需要修正。**

扫描结果显示：在与真实硬件**容量与工况可比**的点上（18.8 kW、环境温度 45 °C），把三项缺失的损耗补齐后，模型 COP = **2.59**，而真实巴士空调同容量实测 COP = **2.76**——模型反而低了 6%。

也就是说，**制冷循环的物理内核是可靠的**。真正的问题是：模型对外报的 `compressor_shaft_power_w` 只算到压缩机轴端，少了三样东西：

| 缺失项 | 量级 | 来源 |
|---|---|---|
| 电机效率 | 0.85~0.92 | 真实锚点反算（Boyard JVSB150Z24） |
| 变频损耗 | 0.94~0.97 | 工程常规值 |
| 冷凝风机功率 | ~275 W（满速） | **`refrigeration.py` 里根本没有风机功率项** |
| 泵功率 | 被低估约 5 倍 | 见发现 3 |

**任何直接拿 `compressor_shaft_power_w` 做能耗结论的数字，都会高估 COP 约 1.3~1.6 倍。** 这是口径问题，不是物理问题。

## 2. 三个新发现

### 发现 1 — 效率图的压比轴完全不覆盖运行区间（最值得警惕）

```python
COMPRESSOR_PRESSURE_RATIO_AXIS = np.array([4.0, 5.0, 6.4, 8.0, 10.0])
```

而模型实际运行压比是 **1.90 ~ 3.44**，全部低于轴下限 4.0。`_compressor_efficiencies()` 里的 `np.clip` 把所有工作点都钳到 4.0 那一列。

后果：**压比对效率的影响在当前仿真里完全没有被建模**。等熵效率恒定取 0.63~0.70，容积效率恒定取 0.88~0.98。扫描结果里 η_is 随转速变化、但不随压比变化，正是这个原因。

风险方向：容积式压缩机在低压比下，内部泄漏再压缩损失减小，但摩擦等固定损失占比上升，等熵效率通常在设计压比（一般 3~5）附近才有峰值。模型把压比 2~3 的效率等同于压比 4 的值，**存在高估可能**——但这需要低压比样本数据才能定论，不能凭推断下修。

建议：把压比轴下延到 2.0，优先用制造商低压比数据补全；Boyard 反算只覆盖压比 5.1 一个点，不足以支撑整条低压比曲线。

### 发现 2 — 泵功率自相矛盾，隐含效率超过 100%

```
CoolantPump.power_w(2400 rpm) = 5.9 W
模型管网 @ 0.60 kg/s 的水力功率   = 22.1 W
隐含泵效率 = 22.1 / 5.9 = 375%
```

物理上不可能。根因是 `LEGACY_REFERENCE_POWER_W = 27.4 W` 来自 Stage 8A 的 legacy 小泵（28 L/min 参考流量），而 Stage 8D4b 把泵放大到 56 L/min（参考流量 ×2）后，**参考功率没有同步更新**。按相似定律，流量 ×2 对应功率 ×8，参考功率应在 220 W 量级而非 27.4 W。

建议：直接从管网水力功率 + 合理泵效率（0.25~0.35）反推，而不是沿用 legacy 常数。

### 发现 3 — 管网阻力假设比真实机组低 4.1 倍

```
模型 @ 0.60 kg/s          : 39.4 kPa  → 水力功率 22.1 W
Jilipow 额定 40 L/min     : 160  kPa  → 水力功率 106.7 W
                            压差比值  4.1x
```

真实机组（40 L/min @ 160 kPa）的泵水力功率是模型的 4.8 倍。若按相同泵效率折算，泵电功耗被低估约 5 倍。

注：`CLUSTER_EQUIPMENT_SIZING_AUDIT.md` 第 10 节已对 20 kPa 支路压降假设做过定性评估，本次用真实机组铭牌数据给出了量化对照。

## 3. 对既有 NMPC 节能结论的影响（需要复核）

NMPC 报告里的节能数字（RegD 工况 −40%）是按**轴功率**算的：

```
基线 0.1483 kWh vs NMPC 0.0890 kWh（600 s，轴端电能当量）
```

补上驱动损耗（÷0.80，对两者同比例，节能率不变）与固定风机功率（275 W × 600 s = 0.0458 kWh，对两者同量相加）后：

```
NMPC : 0.0890/0.80 + 0.0458 = 0.1571 kWh
基线 : 0.1483/0.80 + 0.0458 = 0.2312 kWh
节能率 = 1 − 0.1571/0.2312 = 32.1%
```

若风机取 400 W，节能率降至约 **29.4%**。

**结论：节能方向不变、量级依然显著，但"−40%"会稀释到"约 −29~−32%"。** 对外汇报时需要用修正后的数字，或明确标注口径为轴功率。
