# P模型冷板热网络结构修正结果

日期：2026-07-23  
状态：物理结构修正、验证集选择、独立测试和当前详细对象指令回放完成；尚未提升为正式MPC默认预测器

## 结论

P模型的主要冷板误差来自一处结构错误：详细对象中电池到冷板的换热系数由52个电芯与冷板之间的固定换热系数组成，总值约为520 W/K，与泵速无关；旧P模型却把该系数乘以泵速比的0.8次方，错误地将电芯—冷板导热和冷却液流动强化混在一起。

本轮新增`battery_plate_conductance_model`：

- 历史产物未声明该字段时，继续按`legacy_pump_scaled`解释；
- 新候选明确使用`constant_physical`，电池—冷板导热不再随泵速变化；
- 冷却液侧换热仍保留泵流量的0.8次方关系。

所有数值参数保持冻结。详细制冷循环、Candidate B、L模型、MPC权重、DMAX和PSO均未修改。

## 数据来源复核

原90步影子轨迹生成于2026-07-20，早于2026-07-21至22日的低速压缩机和功率模型修改，不能直接作为当前对象的调参依据。本轮使用当前详细对象，在相同压缩机、泵和电流序列下重新生成90步调峰、调频指令回放，再进行外部复核。

辨识验证集综合加权MAE由0.223766降至0.223723，候选通过严格改善门槛。虽然综合变化较小，但验证集冷板MAE在5、50、100和300秒分别下降约44%、50%、51%和31%，方向与物理结构一致。
