# 极简 GitHub README 设计规范

## 目标

将仓库 GitHub 首页精简为项目名称和一段项目简介，使访问者能快速理解项目用途，同时避免文件清单、运行命令、验证结果和模型细节造成的信息过载。

## 最终内容

```markdown
# 储能电池热管理仿真与控制

本项目面向储能电池热管理系统的建模、仿真与控制研究，集成电池热模型、冷板与冷却液动态、制冷循环，以及 On-Off、PID 和 MPC 控制策略，支持调峰与调频场景分析。
```

## 页面结构

README 只包含以下两项：

1. 一级标题：`储能电池热管理仿真与控制`
2. 一段项目简介

## 明确不包含

- 背景图、横幅、渐变、徽章或其他装饰
- Candidate B、Physics-P 或其他具体预测器说明
- 环境安装、部署、启动或测试命令
- 文件结构、模块职责或项目导航
- 仿真结果、性能指标或验证数据
- 注意事项、历史说明或服务器运行建议

详细技术信息继续保留在仓库现有专项文档中，但不从极简首页展开。

## 实施范围

仅替换根目录 `README.md`。不修改控制器、物理模型、仿真入口、参数资产、测试或其他文档。

## 验收

- `README.md` 与“最终内容”逐字一致。
- 文件为 UTF-8 文本，Markdown 标题和段落可正常渲染。
- README 中不存在命令代码块、表格、图片、徽章、预测器名称或结果指标。
- `git diff --check` 通过。
