# 延迟阶跃响应图设计

## 目标

基于用户指定的有延迟与无延迟 CSV，生成一张简洁的阶跃响应比较图。

## 数据与时间轴

- 输入：`delay_enabled.csv` 与 `delay_bypassed.csv`。
- 仅保留压缩机阶跃之后的数据。
- 横轴定义为阶跃后时间，阶跃瞬间为 `t = 0 s`。

## 图形布局

- 单张 PNG，三行单列子图，共享横轴。
- 子图依次显示：压缩机实际转速、制冷量、冷板入口温度。
- 每个子图仅显示“有延迟”和“无延迟”两条曲线。
- 使用简短中文纵轴名称与单位；不使用总标题。
- 在 `t = 0 s` 标记阶跃位置，但不将该标记加入图例。

## 输出

- 300 dpi PNG。
- 不修改输入 CSV 或热管理仿真模型。

## 验证

- 图中恰有三个子图。
- 每幅子图恰有两条数据曲线。
- 坐标与图例中文显示正常。
